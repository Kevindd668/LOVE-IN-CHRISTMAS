# F4 · 编辑模式

## 1. 入口

```text
正常观看：/
作者编辑：/?edit=1
```

- 正常模式不创建 `StoryEditor`；
- 编辑模式设置 `body.is-edit-mode`，追加“我们的故事”抽屉；
- 关闭抽屉后保留 `?edit=1`，可通过右下角“编辑我们的故事”重新打开。

## 2. 可编辑内容

| 内容 | 字段 |
| --- | --- |
| 她的昵称 | nickname |
| 爱情承诺 | promise |
| 专属信件 | letter |
| 未来约定 | wishes |
| 五个礼物 | giftMessages[0..4] |
| 照片故事 | title / date / description / category |
| 本机保存 | IndexedDB toggle / clear |

## 3. 普通模式

- 控制面板默认收起；
- 不显示照片元数据表单；
- 不显示本机保存开关；
- 照片、礼物、爱心、数字仍可正常互动。

## 4. 自动保存

- 文本内容防抖 450ms 写 localStorage；
- 照片元数据在开启本机保存时防抖 900ms 写 IndexedDB；
- 顶部/底部状态显示保存结果；
- 保存失败不阻塞当前会话。

## 5. 安全边界

- 编辑模式是作者入口，不是安全权限系统；不存放密码或私密凭据；
- 运行时不向服务器发送内容；
- 分享礼物页面时，照片必须通过本地保存或后续离线包随行，不能只依赖作者本机 IndexedDB。
