# Cinematic Intro 设计

## 1. 8 秒时间轴

| 时间 | 阶段 | 画面 |
| --- | --- | --- |
| 0–0.5s | 黑场 | `#080E20` 背景 |
| 0.5–1.0s | 光点 | 中央 `#FF75A9` 微光放大 |
| 1.0–1.5s | 星尘 | 光点脉冲，星尘出现 |
| 1.5–3.0s | 星河爆发 | 20k 三层螺旋，镜头向中心穿越 |
| 3.0–4.5s | 爱心诞生 | 漩涡反向/聚合，3D 爱心，心跳，冲击波 |
| 4.5–6.5s | 标题 | LOVE IN CHRISTMAS，两侧粒子汇聚，金色扫光 |
| 6.5–8.0s | 树登场 | 标题退场，正式树/树顶/灯光/双螺旋亮起 |

## 2. 粒子螺旋

总数 20,000，单 `Points` + 单 `LineSegments` 拖尾：

| 层 | 数量 | 颜色 | 结构 |
| --- | ---: | --- | --- |
| 外层 | 7,000 | `#557BFF` / 冷蓝 | 5 条细旋臂，半径 5.5–13 |
| 中层 | 7,000 | `#FFD58A` / 暖金 | 3 条旋臂，半径 2.6–10.2 |
| 内层 | 6,000 | `#FF75A9` / `#FFD5E5` | 4 条密集旋臂，半径 0.4–6.4 |

每个粒子具有半径、螺旋角、层号、厚度、相位、颜色、尺寸和独立速度。

### 3D 螺旋公式

```text
theta = arm * 2π / armCount
      + ln(r / r0) * tightness
      + random jitter

x = cos(theta) * r
z = sin(theta) * r
y = gaussian thickness + sin(r * 0.8 + phase) * 0.1
```

整体 group 倾斜 `x=0.34, z=0.08`，相机从 z=28 推进到 z≈4，穿过旋臂，不再是二维圆形爆炸。

- 三层不同速度和方向；
- 中心保留暗色空腔；
- 拖尾为同一粒子的切线短线段；
- 星场/星云/极光复用 `GalaxyEnvironment`，隐藏光瀑/轨道/流星。

## 3. 漩涡到爱心

- 3.0s 开始把 20k 粒子位置混合到爱心目标；
- 爱心目标通过 `HeartParticleSystem.copyHeartPositions` 从正式 20k 目标数组读取；
- 保持 3D 厚度；
- 4.1s 心跳，4.0s 用现有 `MagicParticles.ripple` 产生玫瑰金冲击波；
- 不创建第二个爱心系统。

## 4. 标题

标题使用清晰 DOM/CSS，不使用粒子拼字：

- LOVE IN CHRISTMAS
- A STORY WRITTEN JUST FOR YOU
- 一场只属于我们的圣诞故事。

香槟金渐变 + 玫瑰金局部高光 + 金色横线扫光；两侧 600 个 2D 金色粒子汇聚；粒子只做装饰。

## 5. 树登场

- 正式 `ChristmasTree` 对象在开场前隐藏；
- 6.15s 开始 `setBodyReveal` / `setLightsReveal`；
- 正式树顶水晶心、双螺旋、爱心装饰逐步恢复；
- 相机最后过渡到 `CameraManager` 的 home pose；
- 不创建临时树，不重载场景。

## 6. 控制

- 暂停/继续：冻结/恢复时间轴；
- 跳过：直接完成树登场；
- 重播：重置时间轴和粒子位置，不重建 Geometry；
- 退出：恢复进入开场前的相机、场景、UI；
- 结束后控制条保留约 6 秒供重播/退出。
