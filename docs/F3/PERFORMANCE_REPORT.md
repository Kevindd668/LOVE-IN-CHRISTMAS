# F3 性能报告

## 1. 环境与方法

| 项 | 值 |
| --- | --- |
| 时间 | 2026-11-25 |
| 浏览器 | Microsoft Edge / Chromium，有头 |
| GPU | NVIDIA GeForce RTX 3070 Ti Laptop GPU，D3D11 |
| Three.js | 0.160.0 |
| 默认质量 | ultra |
| 采样 | 每个 case 预热约 4s，rAF 采样 4s |
| 原始数据 | `qa/f3/performance.json` |
| 对比基线 | `qa/f0/performance-baseline.json`（F0 commit `c9e3d02`） |

测试分辨率：

- 1440 × 900，DPR 1
- 1920 × 1080，DPR 1
- 4K 等效：1920 × 1080 viewport + DPR 2 → canvas 3840 × 2160
- `?full=1`：完整 Bloom 管线（已验证 `directRendering=false`、`pipeline=true`）

## 2. F3 结果

| Case | 平均 FPS | P95 帧时间 | 最大帧 | Draw calls | Triangles | Points | Textures | Geometries |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 1440×900 兼容 | 95.4 | 16.9 ms | 58.3 ms | 291 | 461,210 | 4,822 | 33 | 195 |
| 1920×1080 兼容 | 113.2 | 16.6 ms | 37.7 ms | 291 | 461,210 | 4,822 | 33 | 196 |
| 4K 等效 兼容 | 80.6 | 25.0 ms | 108.7 ms | 291 | 461,210 | 4,822 | 33 | 196 |
| 1440×900 完整 Bloom | 100.2 | 16.6 ms | 41.6 ms | 305 | 461,224 | 4,822 | 46 | 197 |
| 1920×1080 完整 Bloom | 89.2 | 16.9 ms | 37.5 ms | 305 | 461,224 | 4,822 | 46 | 197 |

所有 case：`contextLost=0`，控制台 0 error；完整 Bloom 的 46 张纹理比兼容路径多 13 张后期目标。

### 结论

- 默认 1440×900/1920×1080 平均 **95–113 FPS**，高于 60 FPS 目标。
- 主分辨率 P95 约 16.6–16.9 ms，接近单帧 60 FPS 的上边界；平均性能充足，但不是“每帧都低于 16.7ms”的硬保证。
- 4K 等效平均 80.6 FPS，P95 25ms；4K 属于记录项，不承诺 4K 稳定 60 FPS。
- 完整 Bloom 100.2/89.2 FPS，pipeline 真实启用，不是“Bloom 开关无效”。
- 4K 有一次 108.7ms 的最大帧，属测量窗口内的单次长帧；P95 25ms。未出现持续长帧或上下文丢失。

## 3. 与 F0 对比

| Case | F0 FPS | F3 FPS | F0 P95 | F3 P95 | F0 calls | F3 calls |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 1440×900 兼容 | 233.9 | 95.4 | 4.3 ms | 16.9 ms | 271 | 291 |
| 1920×1080 兼容 | 224.5 | 113.2 | 8.3 ms | 16.6 ms | 271 | 291 |
| 4K 等效 兼容 | 192.1 | 80.6 | 8.4 ms | 25.0 ms | 271 | 291 |
| 1440×900 完整 Bloom | 196.0 | 100.2 | 8.4 ms | 16.6 ms | 285 | 305 |

解释：

- F3 的三角面从 310,674 增加到 461,210（+48.5%），draw calls 从 271 增加到 291（+7.4%）；主要成本来自 9 层更密的树冠，而不是 360 个真实光源。
- F3 的平均 FPS 低于 F0 的某些历史运行值，但仍显著高于 60 FPS；F0 与 F3 的采样窗口/窗口焦点/刷新率状态存在差异，P95 不能视为严格的同条件 A/B 结论。
- 完整 Bloom 在 F3 下依旧可运行（100.2 FPS @1440），并且 pipeline 被实际验证。

## 4. 资源稳定性

`qa/f3-control-results.json` 记录了连续四次树高重建：

| 重建 | geometries | textures |
| --- | ---: | ---: |
| 1 | 195 | 33 |
| 2 | 195 | 33 |
| 3 | 195 | 33 |
| 4 | 195 | 33 |

未观察到持续增长；新树模块的 `dispose()` 覆盖 TubeGeometry、heart geometry、InstancedMesh、材质、halo 纹理和光源。

## 5. 结论与限制

- 第 16 节要求默认画质 60 FPS 以上：**平均 FPS 达标**；主分辨率 P95 接近 60 FPS；4K 不承诺 60。
- 无重复 renderer、无第二个动画循环、无新增真实逐灯源。
- 仅在本机 Edge 158 + RTX 3070 Ti Laptop 测量；未测移动端、Firefox/Safari 或低端集显。
- 4s 采样和 F0 15s 采样的口径不同；本报告不把差异宣传为严格性能提升/退步比例。
