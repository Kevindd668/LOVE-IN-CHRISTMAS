# 实验 03 · 星河为你亮起

路径：`experiments/03-galaxy-nebula/`  
入口：`http://127.0.0.1:8787/03-galaxy-nebula/`

## 目标

用一套可交互的深空场景同时呈现：多层星空、程序化星云、极光、流星、金色粒子光瀑、三层发光轨道与爱心。

## 来源与实现

| 项 | 内容 |
| --- | --- |
| 参考 | `Interactive-Xmas-Tree`（MIT，main `be75d04`）；`Christmas-Tree-Photos`（main `b5f4870`；作者已授权本项目直接复用） |
| 参考内容 | 星场/相机组织、空间氛围 |
| 实际实现 | 独立 GLSL/Three.js；无参考代码或素材复制 |
| 第三方素材 | 无 |

实现要点：

- 近星 12000 + 远星 6000（可调）；每个点带相位/大小/色相，使用自定义点着色器闪烁。
- 三层程序化星云平面：FBM 噪声、边缘淡出、additive 混合；非静态背景图。
- 四层极光：顶点波动 + FBM 帘幕/边缘衰减着色器。
- 5 颗可循环流星；5000 颗金色光瀑粒子，沿螺旋/下落轨迹循环。
- 三层发光椭圆轨道 + 中心 320 颗爱心粒子 + 粉色光带。
- 相机预设：全景、星云近景、极光近景、光瀑、等待流星；相机平滑过渡。

## 交互与参数

- 星空粒子 / 远景星点 / 流星数量 / 星云层数 / 极光层数 / 光瀑粒子。
- 粉色星云、蓝绿极光、金色光瀑三种颜色。
- Bloom、自动环绕；暂停/重置/复位视角/退出。

## 真实浏览器证据

截图（`experiments/03-galaxy-nebula/screenshots/`）：

`panorama.png`、`nebula-close.png`、`aurora-close.png`、`golden-fall.png`、`meteor.png`、`controls.png`。

实测：

- 约 240 FPS；36 draw calls；约 23000 粒子；无控制台错误。
- 五个相机预设均成功切换；星云/极光/光瀑/流星均可见。

## 已知限制

- 极光是艺术化帘幕/云雾，不是物理极光模拟。
- 光瀑由粒子组成，未做流体解算；在部分角度会显得像密集星尘。
- 参考仓库的图片/贴图未使用；所有背景均为着色器生成。
